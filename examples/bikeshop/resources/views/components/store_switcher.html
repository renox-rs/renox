{#- The store switcher, in the staff layout's top bar (src/app/access/active_store.rs). `store_switcher` is shared with every view by the access area: the store this request works in (`current`) and every store where the person holds `staff.access` today (`stores`), so a dated role (help in another store this week) shows up only between its dates. A layout passes it in as `switcher`. With one store it is a label; with more, the kit's `menu` whose items post to `access.store.switch`, which checks the store again before keeping it in the session. Customers and guests get `none`: nothing is shown. -#}
