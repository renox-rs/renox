001 The problem

A Rust web app today is twenty crates and a week of glue.

Rust gives you speed and a compiler that catches bugs before your users do. But for a web app you pick a router, an ORM, a session store, CSRF protection, a queue, a mailer, templates and migrations, then wire them together and keep them in step. Laravel solved that years ago, without Rust's guarantees. Renox brings that productivity to Rust.

  • →One dependency. renox = "1" and use renox::prelude::*: everything else is already there, and already fits.
  • →Laravel's ideas, Rust's types. Routes, models, form requests, jobs, mailables and policies: names you know, checked at compile time. Laravel → Renox, concept by concept.
  • →Upgrades are a version bump. Apps depend on Renox; framework code is never copied into them.

006 Deploy

Your whole app is one file. Copy it. Run it.

Views, translations, migrations and public files are embedded at build time. The binary is its own CLI too: migrate, queue:work, schedule:work, db:seed. No PHP-FPM, no node_modules, no runtime to keep patched. Running Renox in production.
